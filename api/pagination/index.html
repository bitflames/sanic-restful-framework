    Pagination

    API Reference: Pagination¶

    Pagination behavior is determined by the ViewSet's pagination_class, which defaults to PageNumberPagination. See Pagination for usage.

    from srf.paginator import PageNumberPagination
from srf.views import BaseViewSet


class BookViewSet(BaseViewSet):
    queryset = Book.all()  # Tortoise QuerySet
    schema = BookSchema  # Pydantic model
    pagination_class = PageNumberPagination

    Response structure¶

    The object returned by list() always contains four fields:

    {
  "count": 42,
  "next": true,
  "previous": false,
  "results": [
    {"id": 1, "title": "..."}
  ]
}

    Differences from DRF

    next / previous are booleans, not URLs to the next/previous page. The frontend must construct page numbers itself.

    Query parameters¶

    Parameter Default Rule
    page 1 Falls back to 1 when it is not an integer or is less than 1
    page_size 10 Falls back to 10 when it is not an integer, and is limited to 1 ~ MAX_PAGE_SIZE (default 100)
    • When the page number exceeds the total number of pages, an empty results is returned and count is still the total record count.
    • The upper bound of page_size is controlled by the MAX_PAGE_SIZE class attribute, which subclasses can override.
    • The parameter names are controlled by PAGE_QUERY_PARAM / PAGE_SIZE_QUERY_PARAM.

    PageNumberPagination ¶

    PageNumberPagination(
    queryset: QuerySet[T],
    page: int = 1,
    page_size: int = 10,
    max_page_size: int = MAX_PAGE_SIZE,
)

    Bases: BasePagination

    A simple page number based style that supports page numbers as query parameters. For example:

    /api/users/?page=1 /api/users/?page=2&page_size=100

    Invalid or missing parameters fall back to page=1 / page_size=10.

    Attributes:

    Name Type Description
    MAX_PAGE_SIZE int

    Upper bound accepted for the page_size query parameter.
    PAGE_QUERY_PARAM str

    Name of the query parameter carrying the page number.
    PAGE_SIZE_QUERY_PARAM str

    Name of the query parameter carrying the page size.
    queryset

    The Tortoise QuerySet being paginated.
    page

    Current page number (1-based).
    page_size

    Items per page.
    max_page_size

    Effective page-size cap for this instance.

    serialize_page ¶

    serialize_page(
    schema: type[BaseModel], rows: list[Any]
) -> list[dict[str, Any]]

    Serialize ORM rows through a Reader/Writer schema for list responses.

    Uses a cached TypeAdapter so schema structure is not re-built per row. Row data is still validated on every call; only the adapter is reused.

    serialize_page() uses a TypeAdapter(list[schema]) cached per schema, making it suitable for reuse in custom paginators. PaginationParams is a reusable parameter validation model; PageNumberPagination parses directly from request parameters and does not depend on it.
