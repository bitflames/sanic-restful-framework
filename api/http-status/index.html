    HTTP Status

    API Reference: HTTP Status¶

    HTTPStatus is an IntEnum: it provides readable constant names and can also be passed directly to Sanic as an integer. Use it instead of bare numbers when returning values from ViewSets. See HTTP Status for usage.

    from sanic.response import JSONResponse

from srf.views.http_status import HTTPStatus


async def handler(request):
    return JSONResponse({"ok": True}, status=HTTPStatus.HTTP_201_CREATED)

    Status code enum¶

    HTTPStatus ¶

    Bases: IntEnum

    Descriptive HTTP status codes, for code readability.

    See RFC 2616 - https://www.w3.org/Protocols/rfc2616/rfc2616-sec10.html And RFC 6585 - https://tools.ietf.org/html/rfc6585 And RFC 4918 - https://tools.ietf.org/html/rfc4918

    Range predicates¶

    These functions accept an integer (or an HTTPStatus member) and return a boolean:

    Function Range
    is_informational 100 – 199
    is_success 200 – 299
    is_redirect 300 – 399
    is_client_error 400 – 499
    is_server_error 500 – 599

    Non-standard status codes

    The enum also includes status codes that are not RFC standards or are deprecated, such as HTTP_306_RESERVED and HTTP_509_BANDWIDTH_LIMIT_EXCEEDED. They are kept only for naming completeness.
